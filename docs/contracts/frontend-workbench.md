# 深色评审工作台接口与验收约定

本轮以 ruanzhu 用户说明书界面为参考，保留七阶段评审协议。

- 数据来自真实 API，无数据时显示空状态，不补造官方分数、建议或历史版本。
- 模型配置提交字段限定为 provider/base_url/api_key/model/is_active；密钥只存临时输入状态。
- 量表文件登记真实来源与哈希，支持 JSON/Markdown/PDF/DOCX；已发布版本只读。
- 用户明确确认输入后才推进人工确认门禁；启动失败保留已创建任务。
- 活跃任务每 3 秒刷新，阶段变化/结束同步结果，离开页面取消旧请求更新。
- 部分结果无正式总分，EVIDENCE_AUDIT 表示待证据审计。
- 证据显示实际页码、段落、行号与原文块；无定位时待人工核实。
- 建议编辑只提交动作、验收、优先级、负责人、操作者与理由。

失败验收：空文件、解析失败、字段校验、权重异常、未发布量表、重复启动、模型失败、进程中断、STALE、空结果、证据缺失、建议编辑失败、下载错误可见并可恢复。

验证：前端构建/关键交互测试；真实 FastAPI + SQLite + 模拟模型浏览器闭环；后端回归、交接与参考快照校验。模拟模型不代表真实云模型验证。
