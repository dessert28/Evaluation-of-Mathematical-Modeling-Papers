# 上游审计 Skill 候选

这里是从公开项目复制的候选 skill，全部是**参考副本**，尚未进入运行时加载器。它们用于核对证据链、状态机、七阶段量表、主张审计、稳健性和多模型仲裁设计。

每个目录保留上游命名；对应仓库快照、提交、哈希和许可证见 `references/upstream/*/SOURCE_MANIFEST.json`，能力映射见 [`docs/references/skill-audit-matrix.md`](../../docs/references/skill-audit-matrix.md)。

启用前必须完成：许可证复核、路径去绝对化、输入输出 Schema 适配、证据定位测试、非法 JSON 测试、无证据降级测试和交接日志记录。禁止直接执行这里的上游脚本。
